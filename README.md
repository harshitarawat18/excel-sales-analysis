# Excel Sales Analysis

## About the project
This is my first Excel project as I start learning Data Analytics. I worked with a sales dataset to practise cleaning data, analysing sales, and finding useful patterns.

## What I did
- Cleaned the data by removing duplicates and fixing inconsistent values.
- Used Excel formulas to calculate Gross Sales and Net Sales.
- Applied Conditional Formatting.
- Created Pivot Tables to analyse sales by product, city, salesperson, and month.
- Made charts to understand the sales results.
- Wrote a few business insights based on the analysis.

## Tools used
- Microsoft Excel
- Excel formulas
- Pivot Tables
- Charts and Conditional Formatting

## What I learned
This project helped me practise Excel on a complete dataset instead of learning formulas individually. I also got a better understanding of how Pivot Tables can help summarise data and how the results can be used to make business recommendations.
